EVARA WELLNESS WEBSITE — MULTI-PAGE EDITION

PAGES
- index.html: Home
- product.html: Product details, all six ingredients, preparation and storage
- about.html: About EVARA
- orders.html: Ordering, payment, delivery, collection and order issues
- reviews.html: Customer reviews section and FAQs
- privacy.html: Privacy Policy
- terms.html: Terms & Conditions

FILES
Keep all HTML pages, styles.css, script.js, config.js and the assets folder together in the same website directory. Do not upload only index.html.

WHATSAPP
The supplied WhatsApp Business and Channel links are configured in config.js. Update them there if they change.

SHOPPING BAG
The front-end shopping bag keeps its item count in the visitor's browser when local storage is available and sends an order enquiry to WhatsApp. It does not process online card payments, reserve stock, or store orders in a server database.

BEFORE LAUNCH
Confirm stock, courier availability, delivery fees, COD eligibility, collection arrangements and return handling. Review the Privacy Policy and Terms & Conditions for your actual business practices before publishing.

PUBLISHING
1. Extract the ZIP.
2. Upload the complete folder contents to your hosting provider, keeping all files and the assets folder together.
3. If replacing an existing Netlify site, deploy the extracted website folder as the new site version.
4. Open each page on a phone and desktop and test the navigation, shopping bag and WhatsApp links.

Navigation update: each main page has at most one Next link, placed at the end of the main content, and it points only to the next main page. The homepage community section links to both the WhatsApp Channel and WhatsApp Business.

Contact Us is a dedicated main page at contact.html, linked from the main navigation and footer.
